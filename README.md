# 程式炸彈拆除專家：最後倒數（Defuse a Bomb）

**繁體中文 · 國中一年級 · 雙人遠端合作 · 程式設計教育遊戲**

> 遊戲中所有「炸彈」、模組及線路均為純虛構數位機關。無真實爆裂物、電子電路、危險裝置操作內容。

## 玩法特色

- 同一個 Node.js Web Service 提供網頁與 Socket.IO 即時雙向同步。
- 教師建立房間後取得 6 碼房間代碼；兩名學生分別用自己的電腦輸入代碼及暱稱。
- 學生 A、B 分別擔任「程式分析員」及「拆彈操作員」，**每一關輪流換手**。分析員掌握機密規則並可以核准程式版本；操作員負責卡片排序、編輯條件/迴圈、實際執行；必須雙方協同完成。
- 關卡內有中央動畫核心、倒數、穩定度、錯誤損失、提示扣分、執行追蹤、成功/失敗動畫與音效開關。
- 初學者透過圖像卡片修改指令；進階模式增加條件組合、執行步驟與除錯難度。右側始終顯示由安全指令模型產生的 JavaScript（唯讀）。
- 不使用 \`eval\`、\`new Function\` 或執行任意使用者 JavaScript。真正的判定、權限、計時與積分都由伺服器處理。

## 學習對象與目標

適用國中一年級、具備基礎 Scratch 經驗的學生兩位。目標是理解：

1. **Sequence**：程式的執行順序及逐步驗證。
2. **if / else + Boolean**：AND、OR 與條件成立/不成立。
3. **Loop**：\`for\` 迴圈的起點、終點與增加值。
4. **Debug**：閱讀執行追蹤、找出錯誤、修改並重新測試。

## 四大關卡

| 關卡 | 主題 | 遊戲互動 | 進階內容 |
| --- | --- | --- | --- |
| 1 · 數位線路危機 | Sequence | 拖曳或按箭頭排序安全訊號卡片 | 4 個模組 |
| 2 · 邏輯密碼鎖 | if/else, AND/OR | 選顏色、調門檻、切換布林運算，依多組測資驗證 | 額外 OR 連接的條件群組 |
| 3 · 無限倒數陷阱 | for 迴圈 | 修改 \`start\`、\`limit\`、\`step\`，觀察執行次數與動畫 | 6 次迭代 |
| 4 · 駭客的最終程式 | Debug | 同時修復執行順序、條件式與迴圈 | 更多執行步驟與迭代 |

**避免誤會**：畫面右方的 JavaScript 是對照展示，不是自由文字的 JS 編輯器；為確保學生安全、判定可重現，目前以有限且嚴格驗證的可視化指令模型為唯一可執行格式。

## 兩位學生線上連線

1. 老師打開遊戲首頁，點「教師 · 建立專屬房間」，取得 6 碼代碼。
2. 老師將**房間代碼**透過課程通訊分享給兩位學生，**不可分享教師的本機憑證**。
3. 兩位學生分別打開同一網址，輸入暱稱與房間代碼，點「學生 · 加入任務」。
4. 老師確認兩名學生均在線，設定每關分鐘數（2～20）與基礎/進階難度，按「開始任務」。
5. 分析員查看左側機密目標，把線索口頭或用作戰通訊給操作員；操作員修改卡片/數值。
6. 分析員按「核准」，操作員按「執行程式」。每次修改後必須重新核准。
7. 錯誤會扣 18 點裝置穩定度、15 秒與 35 分；提示每關 2 次，每次扣 25 分。任務成功累積合作分數。
8. 老師用「下一關」或「指定關卡」進行教學。失敗後可按「重試此關」。

網路短暫中斷或重新整理，瀏覽器會利用本機儲存的**獨立、隨機身分憑證**重新連回原房間。建議用 HTTPS 網站，課後使用「離開」清除共用電腦中的登入資訊。

### 安全與持久化限制

- 房主驗證使用獨立 256-bit 隨機 token，在伺服器以 SHA-256 雜湊比對；學生各有不同 token，不能操作另一位的專屬權限。
- 房間狀態暫存於 **Node.js 單一程序記憶體**；**伺服器重啟、Render 免費方案休眠後新程序、重新部署時，原房間可能消失**。可於課前建立新房間。此版本不包含持久化資料庫，也不能部署為多副本。
- 本遊戲只適合教學規模的短時間房間；代碼不是登入密碼，請勿在遊戲內輸入個人或敏感資料。
- 教師無法直接接管任何學生的角色操作。
- 變更關卡會中止目前回合；請在完成該關的結果記錄後切換。

## 教師控制台

教師帳號/身分依建立房間時發出的隨機 token 維持，不是僅憑畫面顯示的「老師」字樣。

可執行：開始、暫停、恢復、調整單關時間及難度、下一關、重試、切到任意關卡、重設房間、挑戰實驗室、實驗室換手。學生進度、各人修改次數、執行次數、錯誤次數與提示使用次數會顯示於特勤小隊面板；教師亦可查看全隊累積分數與關卡歷程。

**注意**：正在進行中的關卡無法臨時修改關卡時間/難度，須先停止並於下一回合使用新設定。

## 挑戰實驗室（第二節課）

老師選「挑戰實驗室」後，分析員可以從下列三種設計模板修改程式目標，發布給操作員破解：

1. **訊號順序**：自訂三種不重複顏色的正確執行序列。
2. **布林密碼**：自訂顏色、能量門檻（20～80）與 AND / OR 邏輯。
3. **迴圈陷阱**：設定應執行 2～10 次的目標。

發布後操作員調整程式、分析員核准；關卡結束後可再發布下一題，或老師按「實驗室換手」交換角色。

## 80 分鐘課堂建議

| 時段 | 活動 |
| --- | --- |
| 第一節 0～5 分 | 建房、進房、故事與角色說明 |
| 5～15 分 | 第 1 關：執行順序 |
| 15～25 分 | 第 2 關：if / else |
| 25～35 分 | 第 3 關：迴圈 |
| 35～40 分 | 階段結算、教師討論 |
| 休息 10 分 | 教師按「暫停」，避免倒數 |
| 第二節 0～10 分 | 第 4 關：綜合 Debug |
| 10～25 分 | 挑戰實驗室：自訂條件、迴圈與順序 |
| 25～35 分 | 老師按「實驗室換手」，互換設計與解題角色 |
| 35～40 分 | 觀看全隊積分、個人操作紀錄，學生送出回饋 |

每關預設倒數 **8 分鐘**，教師可改為 5、8、10、12、15、20 分鐘（伺服器允許 2～20 分鐘）。

## 本機安裝、執行與測試

需 Node.js **20+** 與 npm。

\`\`\`bash
git clone https://github.com/Chuang-Chih-Hao/Defuse-a-bomb.git
cd Defuse-a-bomb
npm install
npm run build
npm start
\`\`\`

瀏覽器開啟 \`http://localhost:3000\`。

- \`npm run dev\`：Node.js watch mode 開發伺服器。
- \`npm run check\`：檢查伺服器與瀏覽器 JavaScript 語法。
- \`npm test\`：執行 Node.js test runner 的邏輯與 Socket.IO 雙人連線整合測試。
- \`npm run build\`：執行語法檢查與測試。**前端是原生 HTML/CSS/JavaScript，無需額外打包**。
- \`GET /health\`：健康檢查，回傳 \`{"ok":true,...}\`。
- \`GET /api/info\`：版本與關卡資訊。

多人測試：在同一台電腦用不同瀏覽器設定檔開 3 個分頁/視窗（確保各自的 localStorage 獨立），或使用三台裝置連同一台主機 IP 與 3000 port。實際上課時應使用公開 HTTPS 網址。

## 正式環境驗證

已建立正式 Render 服務：**https://defuse-a-bomb.onrender.com**。

每次推送 `main`，CI 會先執行本地程式與三瀏覽器整合測試，並從 GitHub Actions runner 對公開 Render 網址進行 `/health`、`/api/info`、首頁及靜態資源的 HTTP 檢查，再讓三個相互獨立的 Chromium 瀏覽器在遠端服務完成四關、實驗室與重新整理的全流程測試。若自動部署期間造成房間重啟，測試允許一次重試。測試結果請以 GitHub Actions 最新綠色執行紀錄為準。

此驗證會建立暫時的測試房間，不會重設正式教學用的房間；請勿在自動部署期間進行正式上課。伺服器重新部署會清除記憶體中的房間。

## Render 建立教學（使用者自行建立）

此儲存庫目前只提供部署組態，**建立 Render 服務需由專案持有者進行**。

1. 登入 Render Dashboard，選擇你的工作區，按 **New → Web Service**。
2. 連接 GitHub 儲存庫 \`Chuang-Chih-Hao/Defuse-a-bomb\`，分支 \`main\`。
3. 設定：Runtime \`Node\`，Root Directory 保持空白，Build Command \`npm install && npm run build\`，Start Command \`npm start\`。
4. Instance 建議先選 Free 測試，Region 可選 Singapore（若提供）。
5. Auto-Deploy 選 \`On Commit\`（自動部署 main）。
6. Render 會提供 \`https://<服務名稱>.onrender.com\` 網址。到 \`/health\` 檢查狀態。
7. 以三台裝置驗證建房、雙人加入、角色隔離、排序與條件判斷、暫停/恢復、重連。

**環境變數**：Render 會自動提供 \`PORT\`；伺服器以 \`process.env.PORT\` 監聽 \`0.0.0.0\`，不需要外部 API 金鑰。此版本採單一進程記憶體房間，不適合 Render 多執行個體負載平衡。
